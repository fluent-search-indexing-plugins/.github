## Troubleshooting Common Issues

Install issues? Narrow the indexed folders when result quality drops.  
Performance problems? Rebuild the index if newly installed apps do not appear.  
License/activation? Disable plugins that add noise rather than useful results.  
Compatibility? Check the hotkey for conflicts with other launchers.  
Update failures? Run as administrator for process actions that require elevation.
